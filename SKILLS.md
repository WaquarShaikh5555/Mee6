# Installed skills

115 Agent Skills across 11 categories, installed under [`skills/`](skills) and linked to `.claude/skills` for automatic discovery.

Each skill is a directory with a `SKILL.md` (YAML frontmatter + instructions) and, where the upstream project ships them, `references/`, `templates/`, or `scripts/` loaded only when the skill is in use.

> Skills are knowledge, not toolchains. Installing one does not install a SDK, simulator, signing identity, or CI runner. See [docs/MOBILE_TOOLCHAIN_REQUIREMENTS.md](docs/MOBILE_TOOLCHAIN_REQUIREMENTS.md).
